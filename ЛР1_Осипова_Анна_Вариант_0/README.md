## 3. Используемые формулы

### Квадратный корень

Решается уравнение:

`x² - a = 0`.

Итерационная формула Ньютона:

`x_(n+1) = 1/2 * (x_n + a/x_n)`.

Критерий остановки:

`|x_(n+1) - x_n| < ε`.

Для `a = 2` начальное приближение:

`x₀ = 2`.

### Кубический корень

Решается уравнение:

`x³ - b = 0`.

Итерационная формула:

`x_(n+1) = (2*x_n + b/x_n²) / 3`.

Для отрицательного `b` в программе отдельно обрабатывается знак.

Для варианта 0:

`b = 10`, `x₀ = 10`.

### Натуральный логарифм

Используется ряд:

`ln(c) = 2 * (y + y³/3 + y⁵/5 + ...)`

где

`y = (c - 1)/(c + 1)`.

Каждый следующий член вычисляется через предыдущую степень `y` с использованием `y²`.

Критерий остановки:

`|t_k| < ε`.

Для `c = 5`:

`y = 2/3`.

## 9. Контрольные вопросы

### 1. Что такое итерационный алгоритм?

Итерационный алгоритм получает решение последовательным уточнением приближений. Каждое новое приближение вычисляется на основе предыдущего. Результативность обеспечивается критерием остановки и ограничением максимального числа итераций.

### 2. Как выводится формула Герона?

Для `F(x) = x² - a`:

`F'(x) = 2x`.

По методу Ньютона:

`x_(n+1) = x_n - (x_n²-a)/(2x_n)`.

После преобразования:

`x_(n+1) = (x_n + a/x_n)/2`.

### 3. Чем отличаются критерии по разности и по невязке?

Критерий по разности проверяет изменение приближений:

`|x_(n+1)-x_n| < ε`.

Критерий по невязке проверяет выполнение исходного уравнения:

`|F(x_n)| < ε`.

Они могут остановить алгоритм на разных итерациях.

### 4. Что такое порядок сходимости?

Порядок сходимости характеризует скорость уменьшения ошибки. Для метода Ньютона при стандартных условиях порядок равен 2, то есть сходимость квадратичная.

### 5. Как влияет начальное приближение?

Чем удачнее начальное приближение, тем меньше итераций обычно требуется. В варианте 0 для `√2` использовано `x₀ = 2`, а для `∛10` — `x₀ = 10`, поэтому для кубического корня потребовалось больше итераций.

### 6. Почему ряд ln(1+x) неудобен для ln(100)?

Для ряда `ln(1+x)` требуется область сходимости `-1 < x ≤ 1`. При `c = 100` значение `x = 99`, поэтому такой ряд неприменим. Преобразование `y = (c-1)/(c+1)` даёт `|y| < 1` для любого `c > 0`.

### 7. Зачем нужна нормализация?

Представление `c = m*2^k` позволяет работать с аргументами, для которых величина `|y|` меньше, поэтому ряд сходится быстрее.

### 8. Почему фактическая погрешность может быть меньше ε?

Критерий остановки является условием для прекращения итераций, а не обязательно точной оценкой абсолютной ошибки. Поэтому фактическая ошибка может оказаться намного меньше ε.

### 9. Зачем нужен N_MAX?

Ограничение защищает программу от бесконечного цикла, если сходимость не достигается.

### 10. Пример итерационной задачи в бизнесе

Внутренняя норма доходности (IRR) определяется как ставка `r`, при которой:

`NPV(r) = 0`.

Значение `r` можно находить итерационным методом, например методом Ньютона.
